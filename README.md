# 형범 · เรียนเกาหลีกับเสือน้อย 🐯

PWA เรียนภาษาเกาหลีจากกิจวัตรประจำวัน สำหรับคนไทยที่เริ่มจากศูนย์ —
ยิ่งเรียน ตัวละครพิกเซลของคุณยิ่งเลเวลอัป และลูกเสือ **범이** จะฟักจากไข่แล้วโตขึ้นเรื่อย ๆ

- 📖 ฮันกึล (สระ + พยัญชนะ) และ 9 ฉากชีวิตประจำวัน (ตื่นนอน → มื้อเช้า → เดินทาง → คาเฟ่ → ร้านอาหาร → ร้านสะดวกซื้อ → ที่บ้าน → ก่อนนอน)
- ✅ กิจวัตรวันนี้: ติ๊กสิ่งที่ทำจริง พร้อมประโยคเกาหลีรูปอดีต
- 🔁 ทบทวนแบบเว้นระยะ (SRS) · 🔊 ฟังเสียงเกาหลี · 🔥 streak
- 🐯 เลี้ยง 범이: ให้อาหาร เล่น พาเข้านอน · 🏪 ซื้อชุด/ของแต่งห้องด้วยเหรียญ
- ใช้งานออฟไลน์ได้ ติดตั้งลงหน้าจอโทรศัพท์ได้ (Add to Home Screen)

```bash
npm install
npm run dev
npm run build
```

ดูรายละเอียดโครงสร้างและกติกาเกมใน `CLAUDE.md`
